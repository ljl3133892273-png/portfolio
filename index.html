智能体矩阵

数据问数 · NL2SQL

检测中

用自然语言直接查业务数据

面向陶瓷品牌经销商体系的 NL2SQL 系统。把「这批砖出了多少平方、哪个系列卖得好」这类业务问题，变成一句自然语言就能问出来的数据。

  • RAG 流程：语义解析 → 关键词扩展 → 元数据检索 → 生成 SQL
  • Qdrant 向量检索字段与指标元数据，为 SQL 生成提供高相关上下文
  • Elasticsearch 倒排索引匹配维度真实取值，支撑 WHERE / GROUP BY
  • TEI + BGE 中文 Embedding 服务，全异步数据库访问

检测中

文档入库到问答检索的全链路 RAG

企业级知识库系统：多格式文档解析入库、向量化存储、语义检索问答。导入与查询双服务分离，支持任务状态跟踪与 MinIO 对象存储。

  • 导入服务(:8100) / 查询服务(:8101) 双服务解耦，独立伸缩

  • BGE 中文向量模型，可配置相似度阈值过滤低质召回
